📌 Project 2: Cart & Checkout Platform

Case Study Title

Improving Checkout Stability and Release Confidence Using Scrum

Context
	•	Domain: E-commerce Core Platform
	•	Teams: 2 Scrum teams
	•	Users: High-traffic transactional flows

Challenges
	•	Performance-sensitive checkout flows
	•	Frequent production incidents
	•	Incomplete user stories reaching sprint planning

Scrum Master Actions
	•	Introduced backlog readiness checklist
	•	Improved story slicing around user journeys
	•	Facilitated defect retrospectives with clear action items
	•	Partnered with Product Owner on priority alignment

Metrics Used
	•	Sprint predictability
	•	Production defect trends
	•	Cycle time per checkout feature

Outcomes
	•	Reduced checkout-related defects by 35%
	•	Improved release confidence and fewer hotfixes
	•	More stable sprint commitments

Real Delivery Scenario

Production issue during sprint
→ Facilitated re-planning without disrupting team morale
→ Ensured transparency with stakeholders
